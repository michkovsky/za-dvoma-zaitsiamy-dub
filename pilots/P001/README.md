# P001 — Проня готує домашніх до візиту кавалера

## Паспорт

Джерело: українська доріжка фільму. Уривок 00:26:30.000–00:27:45.000, 75 секунд. Це пілот, не встановлені драматичні межі повної сцени. Останню репліку обрізано. При повній розмітці треба визначити справжній початок і кінець сцени.

Місце: домашній інтер'єр родини Сірків; точну топографію кімнати та переходу з крамниці ще перевірити по відео. Дія: Проня командує Химкою, намагається надати батькам «благородного» вигляду й повідомляє про кавалера. Комізм — у розриві її претензій із домашнім середовищем.

## Диспозиція

Взаємодії: Проня → Химка (виклик і накази); Проня → Явдоха (хустка, чепчик); Проня → Сірко (галстук); батьки ↔ Проня (спільні відповіді). Це схема адресатів. Точні позиції ліворуч/праворуч, переміщення Химки, місце папуги та моменти передачі предметів ще не розмічені. Їх не слід вважати підтвердженими.

## Текст, виконання та звук

`dialogue.uk.csv` — розшифровка з непевними словами; `en/draft.md` — історичний перекладацький чернетковий текст; `en/performed.md` — текст поточної виконаної версії, має пріоритет для пілота. Репліки про прізвище у цій версії ще містять Holokhvostyi.

Затверджений пілот: media/exports/P001-v1.mp4; контрольні суми — artifacts.csv. Погодження користувача: «Чудово, фрагмент мені сподобався».

У переробленому обміні 00:10.40–00:21.70 старий мікс замінено послідовними фрагментами; фон і відлуння там прибрані. Цілісна відповідь hah-ing займає 00:12.20–00:14.65, прискорення 1.305. Це відомі монтажні властивості прийнятої проби. Переносимий генератор ще не зібрано; історичні застереження збережені у skill scene-dubbing.

## Відкриті питання

- Перевірити непевні слова в dialogue.uk.csv, зокрема відповіді батьків.
- Визначити повні драматичні межі та покадрову диспозицію.
- Погодити застосування Ragtail / de Bragtale.
- Перенести залежності та всі вхідні фрагменти генератора для відтворюваної збірки.
