# Контроль опису дій — протокол

2026-11-09. Продовження FR-004/005 специфікації 005 та RQ-001. Дослідний фрагмент: P002 local 120–195 с (UK source 26:30–27:45), що перекриває P001, але не змінює його матеріали.

Однакові WAV, medium q5_0, Whisper.cpp 1.7.6, Vulkan GTX 1650, uk, threads=4, beam=5, best-of=5, max-context=224, штатний fallback. Три неперекривні вікна по 25 с, кожне в окремому процесі: підказка подається на початку кожного. Умови: A без prompt; B попередній короткий опис; C стислий послідовний опис взаємодії й емоцій без цитат. Незмінні виходи та SHA-256. Зміст C — редакторське трактування за матеріалами P001 і UC-002, не незалежний фактологічний еталон. Неперевірений маршрут із RQ-001 не подавати. Довгий багатoабзацний документ не вміщується в текстове вікно Whisper; тестується його стисла версія.

Перший технічний контроль із max-context=0 збережено окремо та відхилено як тест гіпотези: цей параметр вимикає використання prompt у декодері. Підстава — умова `params.n_max_text_ctx > 0` у src/whisper.cpp v1.7.6, рядок 7077. Однакові тексти A/B/C підтверджують проблему, але не доводять відсутності користі опису.

Після перегляду 25-секундних виходів додано нерозрізаний контроль 75 с з тими самими умовами A/B/C та max-context=224: межа коротких вікон перетинає контрольний обмін UC-001. Це адаптивне доповнення, не заздалегідь визначений повтор. У нерозрізаному варіанті prompt початковий; подальші кроки використовують історію розпізнаного тексту, тому незмінне повторення опису на кожному внутрішньому кроці не гарантується. Повні передані рядки зберігаються, рушій бере до 224 останніх токенів.

Основний незалежний контроль: UC-001, дві відповіді «Простота — не гріх» та «Не гріх». Не включати їх у prompt. Додатково показати зміни решти тексту без оголошення їх правильними. Повного перевіреного UK-еталона немає, тому WER/CER для сцени не обчислювати. Один фрагмент і один запуск на умову не підтверджують узагальненого ефекту.

Переклад перевіряти окремо від ASR: той самий український вхід, та сама модель й інструкція, окремі сесії без спільної історії; єдина зміна — опис. До окремого доручення Copilot виконання цього плеча не починати. Порівнювати зміст, адресата, комічний механізм, додавання та втрати. Авторська оцінка не є незалежним або сліпим рев’ю. TTS у цьому контролі не синтезувати: акторська розмітка не доводить поліпшення звуку.

Точні входи, параметри та результати публікуються разом зі звітом; сирі журнали й WAV — у зовнішньому reports/P002/context-ab. Перші проходи й історичний scene.md зберігаються.
