## Що виправлено

- Окреме «Не гріх» підтверджене за Сірком. V2 уже мала його голос у цьому місці: нової генерації для нього не робили. Першого мовця/унісон користувач не уточнив; це не закрито автоматично. У виконанні перша відповідь Явдохи залишається запропонованим кастингом.
- Проня тепер говорить **five rubles**, а не a few rubles. Подача задана сльозливою й вимогливою: exaggeration=0.8, ритм сповільнено зі збереженням висоти голосу; досягнення емоційного результату має оцінити користувач.
- «No, no, no!» належить Явдосі як материнське заспокоєння з навмисним перебиванням. «Old man!» теж належить їй і звернене до Сірка; голос і манера інші, ніж звернення до дочки. Попереднє Сіркове «No, no!» у цьому місці прибрано як хибне.
- Химку кличуть **по черзі Сірко й Явдоха**, вона відповідає «Hah?». Прибрано вигадане доручення Проні «купи шампанського».
- Відновлено Сіркове **Go to Kondurevych’s.** і його наступний докір. УК-слово **«Пенсійон»** підтверджене користувачем. Finishing school прямо відхилено користувачем. Для Сірка пансіон — модна штука, назву він простолюдно перекручує; знання тривалості навчання йому не приписується. **Ponchun…** у цій пробі є запропонованою користувачем вигаданою формою для голосової проби, не погодженим виконанням. Факт вигнання Проні залишається контекстом персонажа, а не автоматично свідомою оцінкою Сірка.

64 голосові записи: 7 перегенерованих/нових фрагментів для цього кола, решта використана з попередньої проби; додана коротка відповідь Химки бере погоджений Hah. Сталі Le Bragtale / Ragtail і цілісний hah-ing збережені. Нові ID trial-061/062/063 додано без перенумерації попередніх. Історичні v1/v2 і P001 не змінено.
