# Контроль перекладу з описом сцени

2026-11-09. Доручення користувача: два контрольні переклади через Copilot CLI. Продовження RQ-001 і FR-004/005 специфікації 005; це експеримент, а не заміна погодженого P001.

Вхід: незмінний текст 75-секундного перекриття з P001, його чернеткові мовці й [?], плюс дві відповіді UC-001 як явно відокремлене уточнення. Неперевірені слова не оголошувати правильними. В обох умовах абсолютно однакові текст, ID, інструкція та модель. A — без додаткового сценічного опису; B — з послідовністю дій, реакцій і емоцій. Уже погоджені англійські репліки P001 та RU не подавати в жодну умову: перевіряється окреме генерування, не повторення готового перекладу.

Окремі нові сесії Copilot CLI 1.0.107, явна модель gpt-6-luna, однаковий reasoning-effort=medium. Робочі каталоги ізольовані поза репозиторієм; без custom instructions, memory та доступу до джерел, які могли б розкрити опис у контрольній умові. Модель повертає текст, файли не редагує, іншим агентам не делегує. Точні prompts, виходи, session ID, SHA та фактична модель з usage зберігаються. CLI не надає тут зафіксованих seed/temperature: випадковість не ізольована, один результат на умову.

Порівняння авторське, не сліпе та не незалежне. До отримання виходів визначено критерії: (1) збереження змісту й усіх відповідей; (2) правильний адресат та намір; (3) буквальна гра Химки та повтори подружжя; (4) необґрунтовані додавання/втрата [?]; (5) конкретність і доречність акторської подачі. Оцінювати текст перекладу окремо від delivery. Більша кількість емоційних слів сама не є поліпшенням перекладу.

Повний ручний еталон відсутній, тому не обчислювати відсоток точності/переваги. Поява додаткової сценічної інформації в B свідчить про використання контексту, але не підтверджує її істинність за відео. Голоси та TTS не генеруються; користь для звучання цим дослідом не доводиться.
