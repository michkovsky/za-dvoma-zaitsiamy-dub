# Сірко: короткі проби емоційного переходу

Стан: обидві проби відхилено за вимовою Кондуревича (UC-011); емоційного вибору A/B немає. Орієнтир користувача — «Кон-ду-ре-вич». Це не нова прийнята повна сцена. За UC-010 користувач не почув у v3 переходу розважливого доручення в розпачливе «Пенсійон». Прийняття короткої вимови Ponchun (P002-A07) не поширюється автоматично на нові генерації.

## Реальна зміна підходу

V3 застосовувала той самий cached Sirko conditioning до обох реплік і різні scalar exaggeration. До того ж при зведенні окремі репліки вирівнювалися за RMS; це могло послаблювати різницю енергії, але саме по собі не пояснює всього сприйняття інтонації. Негативний результат користувача не спростовується наявністю різних параметрів або SHA.

У новій пробі T3 отримує **окремі speech-condition tokens з оригіналу** для розважливої та розпачливої репліки. Голосова ідентичність зберігається: cached speaker embedding Сірка та його waveform-reference не замінювалися новим голосом. Рівність speaker embedding перевірено, різні суми style tokens зафіксовано в [report.json](report.json). Текст доручення й фонетичний Pon-chun лишаються попередніми.

Вікна оригіналу від початку trial source 26:29.467: 91.05–92.30 с та 92.30–94.00 с. Їхні точні голосові межі proposed; короткий зразок може нести сторонні елементи й не гарантує перенесення потрібної емоції. Оригінальна пара 90.8–94.1 с також збережена зовні. Джерельний файл — виділені UK-голоси, не RU-доріжка.

## Кандидати

У зовнішньому work_dir:

- `exports/P002/emotion-pair-1/pair-A.mp3`: спільне розважливе доручення та Ponchun із source-conditioning, exaggeration=.8 / cfg=.35 / temperature=.65.
- `exports/P002/emotion-pair-1/pair-B.mp3`: **те саме** доручення та інша генерація Ponchun із тим самим розпачливим reference, exaggeration=.98 / cfg=.25 / temperature=.75.

В обох між фразами залишено 0.13 с. Пари унормовано за загальною гучністю, без окремого RMS-вирівнювання двох фраз. Це художні варіанти для вибору, не наукова A/B-абляція: змінюються кілька параметрів і seed, тому причинний внесок кожного не виміряно.

Перший запуск завершив розважливу репліку, але впав при підготовці наступної: inference tensors помилково потрапили в autograd. В окремому процесі вимкнено grad і підготовку conditioning виконано в inference_mode; продовження зберегло готовий WAV і завершило обидва варіанти. Бібліотеки й вихідні записи архіву не редагувалися. Логи збережені в зовнішньому reports/P002/emotion-pair-1.

Перевірено кінцеві SHA та відсутність PCM clipping у парних WAV. **Ці перевірки не підтверджують чутного емоційного зламу.** Запитано оцінку користувача: A, B або жоден. До неї v3 не перезаписується й нова повна сцена не видається як виправлена. Обраний варіант надалі має зберегти відносну динаміку двох реплік у загальному міксі.
