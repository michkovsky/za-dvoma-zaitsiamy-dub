# P002 trial v2 — Ragtail / Le Bragtale та видимі субтитри

Статус: draft виконання. Мовне рішення Ragtail → Le Bragtale для цього обміну погоджене правкою користувача; La було одруківкою. Нове звучання ще потребує прослуховування.

Видавані результати у зовнішньому work_dir:

- `exports/P002/trial-v2/P002-trial-v2.mp4` — повні 109.533 с, 720p, англійські субтитри **напечено в зображення**; нічого в плеєрі вмикати не потрібно.
- `exports/P002/trial-v2/P002-trial-v2.wav` — окремий мікс.
- `P002-trial-v2.en.srt` / `.en.ass` — окремі субтитри для подальшого монтажу.

Змінено тільки три тексти: trial-034, Проня — «Le Bragtale.»; trial-035/036, Сірко та Явдоха — «Ragtail, the barber?». Контраст показної манірності Проні й простого впізнавання батьків тепер є в аудіопробі та написах. Українську транскрипцію цим не змінювали. Для TTS окремо збережено фонетичні підказки `Luh Brag-tail.` і `Rag-tail, the barber?`; написання перекладу та субтитрів від них не змінюється.

V2 зберігає 61 голосовий фрагмент: 30 згенерованих реплік із v1, 3 перегенеровані прізвищні репліки та 28 інших повторно використаних фрагментів. Hah-ing збережено цілісним. V1 і погоджений P001 не перезаписано. [Таблиця застосованих рішень](adaptation-checks.md), [автоматична звірка](adaptation-checks.json), [текст і фонетика](cues.json), [фактичний монтаж](assembly.json), [генерації](generation.json).

Субтитри мають 53 написи: 8 пар однакового хору об’єднано. Експортовано та переглянуто декодовані кадри з Le Bragtale біля 64.1 с та Ragtail біля 65.8 с. Видимість перевірено за пікселями, не за subtitle stream. У кінцевому MP4 написи є частиною відео; окремої доріжки для їх показу не потрібно.

Технічні результати й SHA: [output-report.json](output-report.json), [technical-qa.json](technical-qa.json), [artifacts.csv](../artifacts.csv). QA перевіряє тривалість, семпли clipping, ненавмисні перетини та всі вихідні SHA. Контрольний ASR першої спроби прізвищ зі звичайним написанням видав «the red tail …», тому додано окремі фонетичні підказки й нову генерацію. Це не незалежне підтвердження вимови: ASR може плутати вигадані назви. Прослуховування потрібне для оцінки голосів, інтонації та впізнаваності гри слів.

Причини помилки v1 і зміни вимог описано окремо: [revision-v2-findings.md](../revision-v2-findings.md). Незмінні джерела, UK1/RU/UK2, залежності та залишкові непевності — [trial v1](../trial-v1/README.md). Повна переносимість TTS-стека й остаточний ліпсинк не заявляються.
