# Пілоти

P001 — погоджена проба 00:26:30–00:27:45. Її межі не визначають драматичні сцени фільму. Пілот є еталоном для наступних проб, а не заміною повної розмітки.

[P002](P002/README.md) — експеримент повної підготовки до візиту з двома проходами української транскрипції: до й після опису сцени. Російська доріжка допомагає в обох проходах; P001 та його погодження збережені окремо. Межі P002 поки proposed.

[P003](P003/README.md) — заголовна пісня: два UK-проходи, джерельне уточнення й подальша англійська співана адаптація на оригінальну мелодію. Межі приблизні, виконання ще не створено.
