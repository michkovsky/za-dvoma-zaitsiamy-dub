# За двома зайцями — багатомовна переозвучка

Спільна розмітка українського оригіналу фільму «За двома зайцями» (1961), мовні адаптації та інструменти машинного дубляжу. Перша адаптація — англійська.

## Стан

Погоджений 75-секундний пілот зберігається окремо: [P001](pilots/P001/README.md). Повні драматичні сцени ще не визначено. Є індекс 1015 ключових кадрів MP4 — це опори навігації, а не підтверджені межі сцен. Кілька слів розшифровки пілота ще непевні.

## Локальна робота

Базові скрипти використовують стандартну бібліотеку Python 3.10+. Для медіа потрібні FFmpeg/FFprobe. Спочатку діагностика, потім вибір сумісних інструментів і коротка перевірка потрібної операції.

```powershell
python pipeline/diagnose_runtime.py
python pipeline/validate.py
```

Скопіюйте `media.example.json` у `local/media.json`, задайте шляхи до власних локальних вихідних файлів. Для оновлення індексу: `python pipeline/index_keyframes.py`. Медіа, моделі, кеші й локальні звіти виключені з Git. Авторизацію GitHub також зберігати поза репозиторієм.

Це початкова структура, не готовий переносимий комплект синтезу. Відомі робочі конфігурації збережені у skills; міграція старих генераторів — окреме завдання. Фільм і оригінальні виконання не створені цим проєктом; репозиторій не надає на них прав. Ліцензію на власні код і документацію ще не обрано.
