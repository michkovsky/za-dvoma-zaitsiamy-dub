# Інструменти

Для чистої локальної роботи спочатку налаштувати зовнішній `DUB_WORK_DIR`: [docs/local-workspace.md](../docs/local-workspace.md). Діагностика підтримує `--output`, нарізання — `--output-dir`; явні параметри переважають сесійний default. Без налаштування старі місця запису збережені.

Python 3.10+, стандартна бібліотека; FFmpeg/FFprobe на PATH для медіа. Не встановлювати PyTorch, ONNX Runtime або CUDA заради читання текстових файлів.

- diagnose_runtime.py — інвентаризація CPU/OS, GPU, RAM, диска й версій інструментів; reports/runtime.json у зовнішньому work_dir, local/runtime.json лише legacy default. Базові CPU features і RAM наразі заповнюються для Windows; Linux-поля можуть лишатися null. Це невідоме, а не підтверджена відсутність/підтримка інструкцій. Не доводить придатності ML-бібліотеки без короткого фактичного запуску.
- index_keyframes.py — пакетні прапори FFprobe → source/keyframes.csv, без декодування повного фільму.
- cut_media.py — точний уривок із відео й окремої української аудіодоріжки. Спочатку показує команду; --execute запускає.
- validate.py — CSV, ID, таймкоди, посилання глосарія, відсутність випадкового перекриття у виправленій суперечці та локальні SHA-256 погоджених медіа.

Межі validate.py: спеціальна перевірка перекриття стосується P001/en/exchange.csv; вона не забороняє хор у всіх performed-таблицях. Валідація всіх табличних status, source_start/source_end, повних source/media.csv-хешів та всіх реєстрових зв'язків ще не реалізована. Scene-перевірки пакета 004 поки спроєктовані. Успішний запуск не означає повної перевірки походження або слухової якості.

Перед preview нарізання та index_keyframes.py потрібен local/media.json за media.example.json: зараз ці два скрипти читають його безумовно. Preview не запускає FFmpeg і не створює уривка, але не є режимом без конфігурації. Відсутня конфігурація зараз дає FileNotFoundError; дружню діагностику треба реалізувати окремо. Діагностика середовища може виконуватися до налаштування джерел; для виходів застосовуються правила зовнішнього сховища. Приклад пробної нарізки після налаштування:

```powershell
python pipeline/cut_media.py --id P001 --start 00:26:30.000 --end 00:27:45.000
```

Синтез і фінальне складання ще не перенесені. Історичний сумісний стек описаний у skill runtime-diagnostics/references/legacy-runtime.md; це зафіксована попередня конфігурація, не автоматичний інсталятор.
