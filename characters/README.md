## Профілі та голоси

П’ять наявних .md-профілів містять робочі акторські трактування, уточнені користувачем; це не титрові біографічні факти. Реєстр index.csv може бути ширший за набір готових профілів. Стан конкретної сцени задається окремо. Еталони звуку — references.csv; медіа й conditioning залишаються локально.


Літературна образність та комічні асоціації прізвищ — [name-context.md](name-context.md). Джерельні форми й вимова можуть відрізнятися; зокрема самопредставлення Галахвастов у п’єсі не змінює ID golokhvostyi.
