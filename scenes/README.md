# Сцени

Повна розмітка ще не виконана; index.csv поки порожній. S001… визначаються переглядом із опорою на source/keyframes.csv. Зміна ключового кадру або плану не завжди означає зміну драматичної сцени.

Кожна сцена: README.md за templates/scene.md та dialogue.uk.csv за docs/formats.md; окрема специфікація за офіційним складеним шаблоном із доповненням templates/scene-spec.md. Англійська адаптація — languages/en/scenes/<ID>/. Пілот P001 не включається до цієї нумерації.

coverage.csv обліковує суцільне покриття video, включно з титрами, переходами й unresolved; source/timing.csv задає перевірену часову основу. Порожні таблиці — початковий стан, не завершене покриття. changes/index.csv і change-record зберігають boundary/split/merge, сталі ID й історичні версії. Реальна карта фільму ще не побудована: це наступний окремий пакет після готовності процесу 004.

Процедура — [scene-workflow.md](../docs/scene-workflow.md). Перенесена репліка зберігає ID із префіксом походження в одному canonical-файлі; її не копіюють до кількох сцен. Усі фактичні межі та мовці перевіряються за джерелом, не за умовними fixtures.
