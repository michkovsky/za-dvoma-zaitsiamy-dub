# Оригінальні матеріали

media.csv реєструє файли без локальних абсолютних шляхів. Контрольні суми повного оригіналу ще не обчислені. Джерела зберігаються локально; налаштування — local/media.json за зразком media.example.json.

keyframes.csv містить 1015 ключових відеопакетів MP4, витягнутих FFprobe. Це індекс навігації; періодичні GOP можуть давати ключові кадри без склейки. Не нумерувати ці записи як підтверджені сцени. Відтворення/кадри між опорами перевіряти лише для потрібних ділянок.


Список дійових осіб: [джерела й пріоритет](character-sources.md), [акторські титри](cast-credits.csv), [літературні персонажі](literary-characters.csv).
