# Конституція проєкту «За двома зайцями»

## Core Principles

### I. Працюємо з наявним твором

Оригінальний фільм — джерело виконання, слів, дій і міміки. Підтверджене спостереження, правка користувача, результат розпізнавання та реконструкція мають бути розрізнювані. Не вигадувати відсутні репліки, кадри або біографічні факти під виглядом перевірених. Створення нової розкадровки не є передумовою роботи.

### II. Спільна основа, окремі адаптації

Опис оригіналу, ID персонажів і реплік та межі сцен спільні. Переклад, вимова й акторські рішення конкретної мови — у languages/<код>/. Пілоти відокремлені від хронологічної розмітки фільму. Зміна таймкоду не змінює ID.

### III. Прості формати й обґрунтовані інструменти

Markdown для описів, CSV для таблиць, JSON для машинних налаштувань. Новий формат, залежність або додатковий процес вводити за конкретної потреби. Не переносити великі галузеві схеми заради формальної відповідності.

### IV. Спочатку апаратна сумісність

Перед вибором збірок, установленням важких бібліотек або масовим запуском перевірити CPU/OS instruction support, GPU/VRAM, драйвери та доступні ресурси. Невідоме не вважати підтримуваним. Потім короткий запуск реальної операції. Повторювати перевірку після суттєвих змін середовища. Історія одного комп'ютера не є універсальною конфігурацією.

### V. Зберігаємо виконання та погодження

Смисл, комічна функція, характер, вимова, природність і візуальна синхронізація оцінюються разом. Персонаж має постійну мовну основу, а емоцію — відповідно до сцени. Погоджені варіанти не підміняти експериментами. Схвалення виконання не підтверджує непевні слова оригіналу автоматично.

### VI. Відтворюваність і пропорційна перевірка

Зберігати параметри обробки, походження еталонів і контрольні суми погоджених результатів. Скрипти виконують операції, skills пояснюють застосування й відомі пастки. Перевіряти те, що може реально зламатися: ID, час, мовців, голосові перетини, тривалість і склад збірки. Не прирівнювати автоматичне розпізнавання до прослуховування.

### VII. Зміни через PR і Spec Kit

Усі подальші зміни готуються в окремій гілці й подаються через pull request. Без прямого доручення власника агент не пушить у main і не зливає PR. Суттєві зміни процесу та інструментів проходять етапи встановленого Spec Kit: specification → clarification за потреби → plan → tasks → analysis → implementation → convergence. Читання й виконання інструкції skill у поточній сесії документується окремо від автоматичного виклику. Звичайна редакторська правка може посилатися на чинну специфікацію; PR для неї все одно потрібен.

## Зберігання та сумісність

Публічний Git містить текстові матеріали й інструменти. Медіа, моделі, ключі, локальні конфігурації, середовище CLI й журнали авторизації залишаються поза Git. Встановлений Spec Kit не дає додаткових прав доступу до системи. Перевіряти можливості конкретного агента й версії; не заявляти автоматизацію, яку не перевірено.

## Робочий процес і рецензування

Одна змістовна задача — одна гілка та PR із метою, межами, джерелами, перевірками й відкритими питаннями. Початковий стан — draft. Перед прийняттям усунути блокувальні зауваження й отримати явне погодження власника на поточний склад змін. Нові змістовні коміти після погодження потребують повторного розгляду.

За окремим дорученням можна залучати інші моделі. У висновку зазначаються модель, перевірений коміт/контекст, обмеження, докази й рішення щодо зауважень. Самоперевірка автора не видається за незалежне рецензування. Згода моделей не доводить факту та не дозволяє автоматичного злиття.

## Governance

Конституція визначає правила проєкту; актуальні інструкції користувача та системні дозволи мають вищий пріоритет. Зміни конституції оформлюються PR разом із поясненням у docs/decisions.md; залежні документи узгоджуються без дублювання правил. Версії: major — несумісна зміна принципів, minor — новий принцип/істотне розширення, patch — уточнення. Перевірка PR включає відповідність конституції. Не створювати зайвих погоджень для вже доручених зворотних дій; явне погодження злиття лишається окремим кроком.
