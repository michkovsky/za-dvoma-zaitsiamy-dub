# Технічні специфікації

Для суттєвих змін створювати <номер-назва>/ зі стислими spec.md (що й навіщо, результат і критерії прийняття), plan.md (як, залежності й обмеження), tasks.md (конкретні кроки та перевірка). Це застосування підходу Spec Kit, без обов'язкової автоматизації.

Наступна значна задача: переносимий генератор, який читає таблиці проєкту та локальні шляхи. Старі синтез і складання ще залежать від експериментального середовища; не видавати їх за готовий pipeline.
