# Специфікації

Суттєві зміни ведемо встановленим Spec Kit. Перша: [001-project-workflow](001-project-workflow/spec.md), процес гілок/PR, Codex-сумісність і модельне рецензування. Spec → plan → tasks → analysis → implement → converge. Деталі — CONTRIBUTING.md.

Окрема специфікація не потрібна на кожну репліку чи виправлення імені: звичайна правка посилається на чинні вимоги й проходить PR. Нові вимоги до інструментів або процесу спочатку описуються й аналізуються. Локальний feature pointer у .specify/feature.json не комітиться.

[004-scene-work-planning](004-scene-work-planning/spec.md) визначає процес сценічної основи, правила зміни меж і шаблон окремого пакета сцени. Окрема повна сцена може вимагати власної специфікації й тривалої роботи; це відрізняється від редакторської правки однієї репліки. Після готовності процесу наступний пакет будує реальну карту фільму; фактичні scene ID визначаються за оригіналом, не беруться з fixtures.

[005-p002-two-pass](005-p002-two-pass/spec.md) — окремий пілот P002 підготовки до візиту: два проходи UK із допоміжною RU-доріжкою та описом сцени між ними. Не змінює карту S-сцен і погоджений P001.

[006-p003-title-song](006-p003-title-song/spec.md) — P003, заголовна пісня: джерельна підготовка за процесом P002 та англійське співане виконання зі збереженням мелодії.
