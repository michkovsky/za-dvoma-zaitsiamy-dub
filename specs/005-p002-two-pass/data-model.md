# Матеріали P002

Пілот: ID P002, proposed-межі на названому джерелі, зв'язок із P001. UK no-ads = UK source −5.000 с.

Прохід: номер 1/2, мова, SHA входу/моделі/binary, параметри, точний prompt або відсутність, час і сирі результати. Перший незмінний після опису.

Опис: відеоспостереження, окремі інтерпретації, непевні мовці. Порівняння: час, варіанти, рішення, підстава, залишкова невизначеність. Статуси чинні; машинним сегментам — draft.

Сегмент ASR не отримує новий canonical-ID репліки до редакторського поділу й встановлення мовця. Старі P001 ID та погодження не переоформлюються.
