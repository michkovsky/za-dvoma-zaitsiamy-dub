# Дані делегування

Це поля звичайного текстового завдання та звіту, не новий машинний формат.

- Пропозиція: мета, користь, межі, результат; доручення absent → authorized або declined. Відсутність відповіді не є authorized.
- Завдання: режим implementation/research/review, база SHA, джерела, дозволені файли та операції, критерії, перевірки, зовнішній каталог результатів.
- Результат: CLI version, фактична модель або unknown, session ID коли доступний, база/переглянутий SHA, зміни, фактичні перевірки, обмеження. Основний агент позначає accepted/rejected/deferred із причиною; це не погодження власника.
