- Markdown + CSV; JSON лише для машинних налаштувань і звітів. TBX/DAPT/XLIFF поки не потрібні.
- Погоджений пілот окремо від повних сцен. Ключові кадри MP4 використовуються як опори; це не готова драматична сегментація.

- Практичний досвід інструментів зберігається у skills; апаратна діагностика обов'язкова перед важкими запусками.
- Підтверджений hah-ing зберігається. Ragtail → de Bragtale поки proposed; старий пілот містить Holokhvostyi.
- Сірко: нарочито народна, трохи гротескна манера; Явдоха й Химка: звичайна народна вимова.


## 2026-11-08 — реєстр дійових осіб

Перед розміткою сцен зібрати склад персонажів. Титри — найвищий пріоритет для назв ролей і акторських зіставлень. Вікіпедія та список п’єси — додаткові джерела. Літературних персонажів не вважати автоматично присутніми у фільмі; ролі, яких титри не називають, позначати окремо. Ініціали акторів із титру та повні імена зі статті не змішувати.


## 2026-11-08 — уточнення пріоритету й полів

Титри пріоритетні для наявності ролі та явного зіставлення з актором, а не для основного імені. Явдоха залишається Явдохою, Сірчиха — лише credit_name. Єдине film_status замінено незалежними in_script, in_film, in_credits зі значеннями yes/no/unknown. ID залишаються сталими. Попередні формулювання про загальний пріоритет назв уточнені цим рішенням.


## 2026-11-08 — контекст промовистих імен

Додано словникові опори та окремо позначені творчі інтерпретації Сірка, Голохвостого/Галахвастова та Сірчихи. Самопредставлення Галахвастов підтверджується п’єсою; відповідний таймкод фільму ще належить знайти. Ragtail → de Bragtale лишається proposed. Нові англійські відповідники Сірка й Сірчихи не вигадуються без оцінки ефекту.

## 2026-11-08 — форми називання в діалогах

За уточненням користувача, під час відновлення діалогів розрізняємо, хто і як називає Голохвостого, без нормалізації всіх згадок до реєстрового name. Під час перекладу використовуємо знахідки гри слів відповідно до конкретного вживання, зберігаючи зв’язок з оригінальною реплікою. Нових обов’язкових таблиць для цього наразі не вводимо: достатньо speaker, text, note та source_id.

## 2026-11-08 — культурна маска прізвища

За уточненням користувача, Голохвостий — природне українське прізвище козацького типу в робочому прочитанні; Галахвастов — самоперероблення на російський манер. Англійська пара Ragtail → de Bragtale розглядається як гра rag/brag, tail/tale та престижного de. Це функціональна заміна культурної маски; конкретного родоводу персонажу не приписуємо. Розподіл форм по репліках ще відкритий.
