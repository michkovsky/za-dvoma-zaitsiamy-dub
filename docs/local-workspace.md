# Локальний робочий каталог без сміття в джерелах

Репозиторій містить код і документи. Оригінальний відеокаталог містить джерела.
Робочий каталог зберігається окремо; персональний шлях не комітиться.

```text
<work>/
  config/       локальні налаштування машини
  reports/      інвентаризація й результати перевірок
  cache/        повторно використовувані кеші
  tmp/          одноразові файли операцій
  tools/        ізольовані інструменти, якщо потрібні
  exports/      результати, які зберігаємо
```

Локальний `local/media.json` у репозиторії — мала постійна конфігурація двох
джерельних шляхів та необов'язкового `work_dir`, ігнорована Git. `work_dir` зберігає
обраний зовнішній каталог також для нових процесів. Junction і symlink для цього не потрібні.
Сесійний `DUB_WORK_DIR` задається абсолютним шляхом поза репозиторієм.
Якщо не задано ані змінну, ані локальний work_dir, старі місця запису збережені
для сумісності.

```powershell
$env:DUB_WORK_DIR = '<absolute-external-work-path>'
python -B pipeline/diagnose_runtime.py
python -B pipeline/cut_media.py --id P001 --start 00:26:30.000 --end 00:27:45.000
```

За такого налаштування звіт потрапляє в reports/runtime.json, уривки — в exports/.
Пріоритет: явні `--output <report.json>` / `--output-dir <directory>`, потім
`DUB_WORK_DIR`, потім `work_dir` з локального конфіга, потім legacy default.
Preview нарізання нічого не створює. Execute зберігає FFmpeg `-n`: існуючі
файли не перезаписуються.

Локальний сесійний launcher може задавати TMP/TEMP/TMPDIR, кеші інструментів
і PYTHONDONTWRITEBYTECODE=1. Він не змінює системні змінні чи PowerShell profile.
Встановлення сторонніх інструментів усе одно перевіряється окремо: ці налаштування
не гарантують поведінку всіх програм на комп'ютері.

Для одноразових перевірок використовувати decode-to-null або керовані тимчасові
каталоги. Після операції прибирати її відомі тимчасові файли. Не очищати всі tmp/cache
рекурсивно за загальним шаблоном і не видаляти старі експерименти без окремого рішення.
Reports, tools, cache та exports не вважати автоматично одноразовим сміттям.
